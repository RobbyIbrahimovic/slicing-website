# Notion Style To Do List Website Slicing

Aplikasi *To-Do List* interaktif berbasis web dengan antarmuka terinspirasi dari **Notion**. Website ini dibuat untuk memenuhi tugas praktikum pemprograman web (*slicing website*) menggunakan HTML, Plain CSS, dan JavaScript.
